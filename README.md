# Skill — навыки для Claude Code

Коллекция навыков (skills), которые я использую в своих проектах.

## Навыки

| Навык | Версия | Для чего | Источник |
|---|---|---|---|
| [impeccable](skills/impeccable/SKILL.md) | 4.5.2 | Дизайн и улучшение интерфейсов: редизайн, критика, аудит, доступность, типографика, цвет, анимация | [pbakaus/impeccable](https://github.com/pbakaus/impeccable) · [impeccable.style](https://impeccable.style/docs/) |

## Как подключить к проекту

Скопируйте папку навыка в проект:

```
<проект>/.claude/skills/impeccable/
```

После этого навык вызывается командой `/impeccable` в Claude Code.
